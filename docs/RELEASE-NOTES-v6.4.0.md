# Orcha legacy release notes — v6.4.0

> This release was originally published under the **Orcha Studio** name. The current product brand is **Orcha**; historical tags/assets are not rewritten.

Model Manager + Auto Router + UI/UX Vision Lite.

Highlights:
- Model registry independent from core.
- Add custom Ollama models without code changes.
- RAM Guard and capability-based routing.
- Model selection mode and routing metadata.
- Runtime benchmark and model comparison.
- UI/UX Vision Lite screenshot audit using Moondream vision + Balanced companion reasoning.
- Fallback to Balanced if a selected model fails.
- Windows Portable and macOS DMG included the then-current Model Manager UI.
